# Project: Cyber Security Escape Room VR - story mode (Unity 6000.6, URP, Meta XR SDK v205, Quest 3)

## How this project is built
- All four scenes are **generated by code**: `CSER > Build All Scenes (story mode)` (or `CSER > Build Scene > ...`) builds MainMenu, Ch1_NightShift, Ch2_FredsOffice, Ch3_ServerRoom (`Scripts/Editor/StoryBuilder.cs` + `EscapeRoomBuilder.cs`) and bakes lighting. Change the builder and re-run it; don't hand-edit scenes.
- Story data (chapters, tasks, hints, learning points) lives in `GameData.cs`; narration in `Resources/VO/narration.json` (+ `Tools/generate_vo.ps1` for the WAVs). `ChapterDirector` runs steps: narration, guide beacon, wrist objective. Puzzle logic calls `GameManager.Complete(TaskId)`.
- The Meta XR MCP bridge can drop from the session; call it directly with `python -I Tools/unity_bridge.py <Tool> '<json>'`. Unity's log is `Logs/Editor.log` (project-relative).
- Computer-use screenshots come back grey on this PC: use `Tools/screenshot.ps1` (writes to Screenshots/) and `Tools/focus_window.ps1`. Unity must run on the RTX 5060, not the Intel iGPU, or the Meta XR Simulator can't create swapchains.
- XR rig, grab, distance-grab, ray-canvas, poke-canvas and teleport come from the **Meta Interaction SDK Quick Actions API** (`OVRQuickActionsAPI.AddOVRInteractionRig`, `QuickActionsAPI.Add*`). Don't hand-roll XR input.
- Runtime UI content (cards, workstation "browser", posters, wall board, keypad) is built at runtime with `UIKit` on canvases the builder creates.
- All game text (tasks, hints, learning points) is in `GameData.cs`.

## Verification loop (Meta XR MCP bridge `meta-xr-unity-runtime`)
1. `CompilationTools.ForceRecompile`, wait for the domain reload, then `GetCompilationErrors` must be empty.
2. `UIVerificationTools.ExecuteMenuItem "CSER/Build All Scenes (story mode)"` (or one scene under `CSER/Build Scene/`).
3. `ExecuteMenuItem "Edit/Play Mode/Play"` (toggles play), then `DiagnosticTools.GetErrorSummary` must be clean.
4. Drive the game with `GameManager.DebugClick(label)`, `DebugDrop(item, zone)`, `DebugStatus()`, `Workstation.DebugType/DebugSubmit/DebugTab`, `DoorKeypad.Press`.
5. `ExecuteMenuItem "CSER/Capture Views"` / `"CSER/Capture Head View"` writes PNGs to `Screenshots/`. Look at them.
6. Commit.

## Hard rules
- Never leave the project non-compiling. MonoBehaviours: one class per file, file name = class name.
- The distance-grab wizard adds a "time-out snap zone"; the builder deletes it on purpose (items must stay where they're dropped).
- Drop zones only react to items with `GrabItem.EverHeld`.
- Runtime UI must build inside `UIKit.ContentRoot(canvas)`: the ISDK canvas interaction objects live inside the canvas and must never be cleared.
- Depth precision: camera near/far 0.05/60; keep labels/decals >= 1 mm off surfaces (z-fighting).
- Avoid non-Latin glyphs/emoji in UI text (LiberationSans SDF lacks them).
- Assets: CC0/public domain only, logged in `CREDITS.md`. No assets or text copied from the reference game.
- Quest perf: baked area lights + light probes, one mixed spot for shadows, textures max 1024, static batching; post-processing off on Android (PlatformTuning).
